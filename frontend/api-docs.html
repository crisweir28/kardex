API Kardex Escolar

http://localhost:3000/api v1.0.0

Sistema de Kardex Escolar — REST API

API para gestión de alumnos, materias, docentes y calificaciones. Autenticación por sesión con cookies httpOnly. Todos los endpoints devuelven JSON.

Base URL: http://localhost:3000/api

auth

Autenticación y sesiones
▼
POST /auth/login Login de alumno ▶
Parámetros (Body JSON)
NombreDescripción
matriculastringMatrícula del alumno (ej. A010) * requerido
passwordstringContraseña en texto plano * requerido
Ejemplo
POST /api/auth/login
Content-Type: application/json

{
  "matricula": "A010",
  "password": "pass123"
}
Respuestas
200Login exitoso — devuelve datos del alumno y establece cookie de sesión
401Credenciales incorrectas
POST /auth/admin/login Login de administrador ▶
Parámetros (Body JSON)
NombreDescripción
usuariostringNombre de usuario admin * requerido
passwordstringContraseña * requerido
Ejemplo
{ "usuario": "admin", "password": "admin123" }
Respuestas
200Login exitoso
401Credenciales incorrectas
POST /auth/docente/login Login de docente ▶
Parámetros (Body JSON)
NombreDescripción
matriculastringMatrícula del docente (ej. D001) * requerido
passwordstringContraseña * requerido
Respuestas
200Login exitoso
401Credenciales incorrectas
POST /auth/logout Cerrar sesión activa ▶

No requiere body. Destruye la sesión del usuario autenticado.

Respuestas
200Sesión cerrada correctamente

alumnos

Gestión de alumnos (Admin)
▼
GET /admin/alumnos Listar todos los alumnos ▶
🔒 Requiere sesión de admin
Respuesta 200
[
  { "id": 1, "matricula": "A010", "nombre": "Luis", "apellidos": "Martínez", "carrera": "..." },
  ...
]
POST /admin/alumnos Crear nuevo alumno ▶
🔒 Requiere sesión de admin
Parámetros (Body JSON)
NombreDescripción
matriculastringMatrícula única * requerido
nombrestringNombre(s) * requerido
apellidosstringApellidos * requerido
carrerastringNombre de la carrera * requerido
passwordstringContraseña (se hashea con bcrypt) * requerido
Ejemplo
{
  "matricula": "A099",
  "nombre": "Juan",
  "apellidos": "Pérez López",
  "carrera": "Ingeniería en Sistemas",
  "password": "pass123"
}
Respuestas
200Alumno creado correctamente
400Matrícula ya existente u otros errores de validación
DELETE /admin/alumnos/{id} Eliminar alumno y sus calificaciones ▶
🔒 Requiere sesión de admin
Path Parameters
NombreDescripción
idintegerID del alumno en la tabla alumnos * requerido
Respuestas
200Alumno eliminado (cascada a calificaciones)
404Alumno no encontrado

calificaciones

Gestión de calificaciones (Admin)
▼
POST /admin/calificaciones Asignar calificación individual ▶
🔒 Requiere sesión de admin
NombreDescripción
matriculastringMatrícula del alumno * requerido
clave_materiastringClave de la materia * requerido
semestrestringNombre del semestre * requerido
calificaciondecimalCalificación 0-10 * requerido
{ "matricula": "A010", "clave_materia": "MAT101", "semestre": "2024-1", "calificacion": 9.5 }
POST /admin/calificaciones/bulk Asignar múltiples calificaciones a un alumno ▶
🔒 Requiere sesión de admin
Ejemplo
{
  "matricula": "A010",
  "calificaciones": [
    { "clave_materia": "MAT101", "semestre": "2024-1", "calificacion": 9.5 },
    { "clave_materia": "PRG101", "semestre": "2024-1", "calificacion": 8.0 }
  ]
}
Respuestas
200{ "mensaje": "2 calificaciones asignadas correctamente" }
PUT /admin/calificaciones Editar calificación existente ▶
🔒 Requiere sesión de admin
{ "matricula": "A010", "clave_materia": "MAT101", "semestre": "2024-1", "calificacion": 10.0 }
DELETE /admin/calificaciones Eliminar calificación ▶
🔒 Requiere sesión de admin
{ "matricula": "A010", "clave_materia": "MAT101", "semestre": "2024-1" }
